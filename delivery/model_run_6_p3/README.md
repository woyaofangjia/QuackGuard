## 2. 稳定性

- `model_gateway.py`：429/5xx/网络错误按 1→2→4→8 s 指数退避，最多重试 4 次；
  4xx（除 429）立即失败；解析错误不重试。
- 可选本地缓存：设置 `QUACKGUARD_MODEL_CACHE` 后，以“模型 + 完整 messages（含图片 base64）+ max_tokens”的 SHA-256 为键缓存返回文本；
  默认关闭，不改变评测行为；演示时可 0 延迟复用。
- 最终全量在退避机制下 0 执行错误；此前无退避的运行曾出现 15 次 429。
